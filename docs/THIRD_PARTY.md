# Third-party sources and licensing

PixelBC runtime code and the BC1–5 GPU decoder are newly written under the root MIT license. PixelBC0.1.2's BC7 GPU decoder adapts the algorithm and partition/anchor tables from Sergii Kudlai's pinned bcdec0.98 under its MIT license; original copyright and the complete permission notice are included in the package NOTICE. The CPU test reference remains independent code executed on the host/probe; it is not linked into the driver library. `src/android_hal.h` reproduces the minimal public AOSP C ABI declarations under Apache-2.0; [hardware.h](https://github.com/aosp-mirror/platform_hardware_libhardware/blob/cd2b68d71a1dd9a45668ddd9a507000ccd7ff114/include_all/hardware/hardware.h) and [Android17 hwvulkan.h](https://github.com/GrapheneOS/platform_frameworks_native/blob/1c83ac6ae533c74ecb0486369c0d2f9e79783b3d/vulkan/include/hardware/hwvulkan.h) are the interface references. The declarations are a reduced, modified interface snapshot: Copyright (C)2008 The Android Open Source Project; Copyright2015 The Android Open Source Project. The complete license is in `licenses/Apache-2.0.txt`.

`tests/reference_bcdec.h` originates from Leegao's pinned wrapper commit c8baafbd4f4835ca103acb55ec3ac13642b6b7e3, `src/vulkan/wrapper/bcdec.h`, version0.98, copyright2022 Sergii Kudlai. We select its MIT license (`licenses/bcdec-MIT.txt`). It is an independent CPU test reference; it is not linked into the driver library. Its original notices remain in the header. PixelBC0.1.1 applies a marked local portability patch: integer and floating signed endpoints use explicit byte arithmetic instead of plain `char`, and integer output uses `signed char`. Interpolation and unsigned decoding are unchanged. The original pinned file SHA256 is `8c972cdebba2c799d8d7478fc676be6d89a95294f012985a4253d80e82d0785d`; the delivery patch shows every local change. Plain `char` is unsigned on Android ARM64, so the original signed reference gave incorrect expectations there. Exhaustive signed endpoint/selector checks compile under both char modes; independent literal fixtures and direct GPU byte checks provide additional anchors.

The ARM64 library and probe statically link NDK r30 libc++, libc++abi and compiler support as selected by the official NDK toolchain. The complete bundled toolchain runtime notices, including Apache-2.0 with LLVM exceptions and libc++/libc++abi notices, are preserved in `licenses/NDK-R30-runtime-NOTICE.txt`. Required NDK/system header notices are covered by those original notices and the AOSP interface license. The package includes root LICENSE and combined NOTICE text. The library dynamically depends only on installed Android NDK public system libraries; the stock vendor Mali driver and its dependencies are not distributed.

Mesa/Leegao, adrenotools, NFS renderer and Bionic sources were inspected for mechanisms. Their repositories, toolchains, game assets and binaries are not included in the driver ZIP. Exact research/build pins are in `sources.lock.json`. No game APK, ISO, assets, saves or credentials are included.
